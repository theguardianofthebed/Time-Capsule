> Temporary initialization-only guidance. Role B will later maintain the full contribution workflow.

## Commit Tag Convention

Use one leading tag in each commit message:

- `[init]` — repository or project initialization
- `[feat]` — new feature
- `[fix]` — bug fix
- `[docs]` — documentation-only change
- `[test]` — tests
- `[refactor]` — code restructuring without intended behavior change
- `[chore]` — maintenance or configuration

Example:

```text
[feat] add local capsule creation screen
```

This convention is temporary and may be revised when the team finalizes its contribution rules.
